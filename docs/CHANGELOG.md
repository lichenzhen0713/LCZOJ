# 版本日志 · CHANGELOG

> 版本号与 `package.json` 一致，系统设置页右上角显示当前版本，点击「版本日志」可回到本页。

完整版本线：**v0.1.0 → v0.7.0**（v1.0.0 之前的历代版本，编号按改动大小重新分配）→ **v1.0.0 → v2.7.5**（当前线）。

**近期重点**
- **v2.7.0**：板块与分类后台自行管理
- **v2.6.x**：安装体验、清理工具、评测设置、提交筛选、数据重置

## v2.5.0（大更新）

> 安全与稳定性的大版本：判题环境全面隔离降权，账号 / 验证码 / 权限体系整体加固，判题与界面统计的一批长期问题同时收口。

**安全加固**
- 判题进程降权到专用低权账户，输入 / 答案 / 采样通道放入独立隐藏目录，符号链接一律拒绝。
- systemd / Docker 加固：低权账户运行、只读根文件系统、权限与能力收窄。
- 账号与会话安全：口令强度策略、登录失败锁定、验证码改用密码学安全随机数生成且只走邮件、改密后自动吊销其它会话。
- 权限与可见性：修复管理员自我提权漏洞；提交记录按权限收口；OI 赛制比赛结束前对他人遮蔽成绩。
- Web 与文件安全：安全响应头、同源（CSRF）校验、请求体超限返回 413、ZIP 解压体积与条目上限、Markdown 链接协议白名单、头像上传魔数校验、更新包与部署脚本下载校验哈希。

**判题**
- 交互题接入内存与总时长判定，超限分别判 MLE / TLE，提示可区分。
- Special Judge 修正 checker 编译缓存；支持部分分输出。
- 选手输出与编译日志加上限；TLE 按实测用时判定；交互器异常判 SE。
- 提交答案题 ZIP 超限改判编译错误并说明原因。

**界面与统计**
- 提交次数按真实总数显示，历史最高分走全量数据。
- 内存未采样时显示 `—`；无子任务时显示总用时；全站用时格式统一。
- 系统设置各卡片重复标题移除；新增徽标与滑块控件。

**注册与邮箱验证**
- 未完成邮箱验证不再创建账号，只在服务端留下待验证记录。
- 重复注册覆盖旧记录；重发验证码旧码立即失效；重发接口不暴露邮箱是否已注册。
- 关闭邮箱验证时注册仍直接建号；老账号在开启验证时可用验证页补验证。
- 判题内存采样可靠性提升。

## v0.7.0

**新增**
- 题目附件：题目可上传附件（列表 / 下载 / 删除）。
- 头像文件存储：头像改为文件保存，数据库只存短地址，接口返回数据更小。
- 题目导入：支持以 JSON / ZIP 批量导入题目。

**优化**
- 评测记录改版：提交记录列表只显示「Accepted / Unaccepted」两种状态（评测中原样显示），具体判定移到鼠标悬停提示。
- 界面样式大范围整理（附件列表、私信会话、头像与导航按钮）。
- 判题机支持 Go 构建缓存回收。
- 连接保活：站内频繁跳转复用同一条 TCP 连接。

## v0.3.0

**新增**
- 题目分板块：每道题拥有独立的讨论板块（板块名为「题号 + 题名」），与「题目总版」相互独立；在题目分板块发帖会显示所属分板块名。
- 题目总版：与学术版 / 灌水区 / 站务版并列的独立板块；分板块的筛选里也能选择它；「全部板块」包含题目分板块的内容；讨论信息的「所属板块」可点击跳转。
- 启用正式数据库，数据不再随进程临时存放。
